# MOTIVE Android — MVP
تطبيق إنتاجية Android باستخدام Kotlin وJetpack Compose وRoom وMedia3.

## التشغيل
1. فك ضغط المشروع.
2. افتح المجلد في Android Studio.
3. استخدم JDK 17 وAndroid SDK 34.
4. نفّذ Gradle Sync ثم شغّل التطبيق.

## الوظائف
- الرئيسية ومؤشر إنجاز المهام.
- إنشاء المهام وإكمالها وحذفها مع حفظ محلي Room.
- استيراد الفيديوهات من الجهاز وتشغيلها عبر Media3 وحذفها من المكتبة.
- إحصائيات المهام والمكتبة.
- إعداد اللغة العربية/الإنجليزية ودعم RTL.
- GitHub Actions للاختبار وبناء Debug APK.

هذه نسخة MVP أولى وليست إصداراً نهائياً. لم يتم اختبار البناء في بيئة Android SDK هنا، لذلك يجب التأكد من نجاح Gradle Sync والبناء قبل النشر.
